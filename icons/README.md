# Icons

These are placeholder SVG icons. For production use, replace with proper PNG icons generated using:

1. Online tool: https://realfavicongenerator.net/
2. ImageMagick: `convert -size 512x512 xc:#1976d2 -gravity center -pointsize 280 -fill white -annotate +0+0 "⚽" icon-512x512.png`
3. Design tool: Create proper icons in Figma/Photoshop

The current SVG placeholders will work but proper PNG icons are recommended for best compatibility.
